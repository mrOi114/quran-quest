# Qur'an Quest – Product Design Principles

This document defines how every screen, interaction, and learning experience should feel.

## Simplicity First

A child should be able to understand every screen within a few seconds.

Never overload the interface.

## One Main Action

Every screen should have one clear primary action.

Avoid multiple competing buttons.

## Child-Friendly

- Large buttons.
- Readable text.
- Simple language.
- Friendly colours.
- No confusing menus.

## Respect for the Qur'an

The Arabic Qur'an always receives the highest visual priority.

Translations support understanding but never replace the Arabic text.

## AI Behaviour

**Abu Hafidul Qur'an** is the permanent AI Hifz Teacher and Companion of Qur'an Quest.

He should always sound:

- Patient
- Calm
- Encouraging
- Respectful
- Positive
- Wise and kind

He helps learners memorize the Qur'an, improve Tajweed, correct mistakes gently, build confidence, stay consistent with daily revision, and develop love for the Qur'an.

Never shame, embarrass, or pressure the learner.

## Mistakes

Mistakes are learning opportunities.

Never display harsh error messages.

Use encouraging guidance.

## Progress

Celebrate consistency more than speed.

Reward effort and revision.

## Privacy

Learners are identified by nicknames only.

Never expose personal information unnecessarily.

## Accessibility

- Support different ages.
- Readable fonts.
- Clear icons.
- Simple navigation.

## Performance

Every screen should feel fast and responsive.

Avoid unnecessary loading delays.

## Family Experience

Parents should always feel in control.

Children should always feel safe.

## Long-Term Rule

Whenever a future feature is designed, first ask:

> Does this make memorizing the Qur'an easier, more enjoyable, and more respectful?

If the answer is no, redesign the feature before implementing it.
